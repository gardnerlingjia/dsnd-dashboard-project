# employee_events

Python package for querying the employee_events SQLite database.

## Installation

```bash
pip install -e .
```
 
## Build Package

```bash
python setup.py sdist
```

The generated package will be placed in:
```text
dist/
```
## Contents
- employee.py
- team.py
- query_base.py
- sql_execution.py
- employee_events.db

## Description
The package provides reusable Python APIs for querying employee and team performance data from the employee_events database.
